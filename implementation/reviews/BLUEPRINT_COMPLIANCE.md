# Blueprint Compliance Review

> Run after every implementation phase. Output lives here.

---

## Per-phase questions

For every phase, answer:

1. What exact blueprint requirements were implemented?
2. Which screen acceptance criteria were satisfied?
3. Which requirements remain incomplete?
4. Did the coding agent add unsupported features?
5. Did screen hierarchy change?
6. Did navigation change?
7. Did business logic change?
8. Did spacing drift from tokens?
9. Did colours drift?
10. Did component architecture drift?
11. Were loading / empty / error states omitted?
12. Did tablet behaviour remain within scope?
13. Did any direct-supplier interaction accidentally appear?

Any failure returns implementation to the responsible specialist.
