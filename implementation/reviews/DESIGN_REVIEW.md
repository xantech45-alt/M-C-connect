# Design Review

> Visual fidelity vs. blueprint, PPT, and supplied mobile references.

---

## Per-screen checklist

- Page composition matches mobile references' hierarchy.
- M&C wordmark visible where required.
- Whitespace generous; no cramped sections.
- Product-image size matches blueprint ratios (1:1 default).
- Card hierarchy: image → title → price → MOQ → verification.
- Red usage: ≤ 12% surface; one dominant red CTA per screen.
- Icon size: 24 dp default; consistent family (Lucide).
- Typography: Inter, weights 400/500/600/700 only.
- Bottom navigation: 5 tabs, 64 dp, red active.
- CTA placement: thumb zone, 60% screen height.
- Content density: ≤ 6 primary regions on mobile.
