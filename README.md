# M&C Connect

M&C Connect is a managed B2B digital sourcing and import platform that connects Malian businesses with verified Chinese manufacturing capabilities. M&C owns every step between product discovery and last-mile delivery inside Mali — customers never deal with suppliers directly.

## Stack

- React 18 + TypeScript
- Vite
- React Router
- Recharts, Swiper, lucide-react

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Script | Purpose |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Type-check and build for production |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
| `npm run format` | Format `src/` with Prettier |
| `npm run typecheck` | Run `tsc -b` without emitting |
| `npm run test` | Run the test suite once with Vitest |
| `npm run test:watch` | Run Vitest in watch mode |

## Project structure

- `src/` — application source
- `public/` — static assets
- `assets/` — design assets
- `blueprint/` — frontend architecture and design system documentation
- `docs/` — supplementary design references
