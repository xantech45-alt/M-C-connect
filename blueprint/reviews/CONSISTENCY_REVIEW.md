# Consistency Review

> Cross-screen consistency after all 24 screens are designed.

---

## Checklist

### Header consistency
- [ ] Title typography identical across screens.
- [ ] Back affordance identical.
- [ ] Right contextual actions placed in same location.

### Bottom nav consistency
- [ ] Five tabs identical across screens.
- [ ] Active tab indicator identical.
- [ ] Hide rule applied uniformly.

### Button consistency
- [ ] Primary red identical across screens.
- [ ] Secondary outlined identical across screens.
- [ ] Tertiary text links identical.

### Product card consistency
- [ ] Image ratio identical.
- [ ] Title clamp rules identical.
- [ ] Price placement identical.
- [ ] MOQ placement identical.

### Price formatting
- [ ] All prices `XX XXX FCFA` (no decimals).
- [ ] Tier pricing format identical.

### MOQ terminology
- [ ] Always "MOQ : X unités".
- [ ] Never abbreviated otherwise.

### Order status terminology
- [ ] French labels identical.
- [ ] Visual treatment identical.

### Icon consistency
- [ ] Line icons same family.
- [ ] Stroke identical.

### Grid consistency
- [ ] 2-col on phones.
- [ ] 3-col on tablet.

### Card radius consistency
- [ ] `radius-lg` 12 dp.
- [ ] Pills 999 dp.

### Spacing consistency
- [ ] Section gap 24 dp.
- [ ] Card padding 16 dp.

### Form label consistency
- [ ] Label above field.
- [ ] Helper below field.
- [ ] Error below helper.

### Empty states
- [ ] Same structure across screens.
- [ ] Same illustration style.

### Error states
- [ ] Same banner style.
- [ ] Same retry pattern.

### Loading states
- [ ] Skeleton shape matches content.
- [ ] Spinner only inside buttons.

### Sticky actions
- [ ] Same height (72 dp + safe area).
- [ ] Same button style.

### Back navigation
- [ ] Hardware back mirrors in-app.
- [ ] Sheet dismisses before navigation.

### French copy
- [ ] Tone consistent.
- [ ] No mixed locales.

### Image ratio
- [ ] Per-surface ratio respected.

## Decisions

- D-CR01 Cross-screen consistency enforced before release.
- D-CR02 Deviations require ADR.
